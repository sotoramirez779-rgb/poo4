# Sistema de Biblioteca - PA4 Programación Orientada a Objetos

## Descripción
Sistema en Java que administra materiales (libros y revistas) en una colección
HashSet, con jerarquía de clases, interfaz, clase abstracta, búsqueda y
ordenamiento.

## Ejecución
1. Abrir el proyecto en IntelliJ IDEA (JDK 17+).
2. Ejecutar la clase `Main` (Shift + F10).

## Diseño
Prestable (interfaz) -> Material (abstracta) -> Libro, Revista
